# SSD1306 — Notes, defaults, and driver usage

Notes for the `SSD1306` driver (I2C monochrome OLED, printf-style text).

## Wiring

I2C — **shares the DAC's already-created I2C0 bus** rather than creating its
own. ESP-IDF only allows one `i2c_master_bus_handle_t` per physical bus, and
the DAC claims I2C0 first at boot; `SSD1306_init` just calls
`i2c_master_bus_add_device()` to attach as a second device (different
address) on that existing bus, and creates its own `i2c_owner_t` wrapping
the same bus handle so its writes get their own FIFO-ordered queue,
independent of the DAC's.

Address/width/height are `idf.py menuconfig`-configurable — see
`docs/HARDWARE.md`. Common default address is `0x3C` (some boards use
`0x3D`); height must be a multiple of 8.

## Driver APIs (primary)

- `SSD1306_start(oled, bus)` — the one-call bootstrap used by `app_main`:
  `SSD1306_init` with the Kconfig-configured address/width/height, plus a
  one-line boot message so there's visible output before anything connects
  over UART. Logs and returns the init error rather than aborting — the
  OLED isn't critical enough to fail boot over.
- `SSD1306_init(oled, bus, addr, width, height)` — lower-level init if you
  need non-default parameters.
- `SSD1306_clear(oled)` — clears the in-RAM framebuffer only.
- `SSD1306_display(oled)` — flushes the whole framebuffer to the panel over
  I2C as one transaction (column/page address range set once, then the
  whole buffer streamed).
- `SSD1306_set_cursor(oled, col, row)` — text-cell coordinates.
- `SSD1306_write_str` / `SSD1306_printf` / `SSD1306_vprintf` — render text
  into the framebuffer at the cursor (does **not** touch the panel — call
  `SSD1306_display` after). Auto-wraps at the right edge to the next text
  row; wraps from the bottom row back to row 0 (no scrolling). `\n` advances
  a row, `\r` resets the column.
- `SSD1306_set_contrast` / `SSD1306_set_invert` / `SSD1306_set_power` —
  panel controls.

Font: standard 5x7 monochrome ASCII (0x20–0x7E), 1px inter-glyph gap (6px
wide x 8px tall cells). Sourced from Adafruit's `glcdfont.c` (BSD-style
licensed, the same table used by countless embedded display libraries) —
see the comment above the table in `SSD1306.c` for provenance.

## Where to find the driver code

- `App/drivers/SSD1306.h` / `App/drivers/SSD1306.c`
- UART command bridge: `App/drivers/uart_bridge.c` (task 4, see
  `docs/UART_PROTOCOL.md` for the wire command format — clear / set-cursor /
  print / display / contrast / invert / power)
- Manual control from the PC: `pc_tools` GUI → `manualCtrl` → "SSD1306
  OLED..."
