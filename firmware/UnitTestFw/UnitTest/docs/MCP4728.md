# MCP4728 — Notes, defaults, and driver usage

This document records the command-format defaults and usage notes for the `DcDac` driver (MCP4728 family).

Datasheet
- Official Microchip datasheet (recommended reference):
  https://ww1.microchip.com/downloads/aemDocuments/documents/OTH/ProductDocuments/DataSheets/22187E.pdf

Driver defaults (conservative / datasheet-aligned)
- Fast write base: `0x00` — used for minimal fast writes on ACK-only devices.
- Write-and-update base: `0x40` — used to write a single channel and update output immediately.
- EEPROM write base: `0x60` — used to write channel value to non-volatile memory (use sparingly).
- Read probe length: `8` bytes (used by auto-detect to read status + DAC values where supported).

Cautions
- EEPROM writes are persistent and limited in write cycles; do not perform in normal runtime loops.
- The driver attempts safe defaults and auto-detection but different part markings or clones may require overriding command bits.

Driver APIs (primary)
- `DcDac_init(DcDacClass *dac, int sda_gpio, int scl_gpio, uint8_t addr, uint32_t clk_hz, DcDacVariant variant)` — initialize. Pass `DCDAC_VARIANT_UNKNOWN` to auto-detect or a specific `DCDAC_VARIANT_MCP4728_AD` to set AD defaults.
- `DcDac_set_channel_percent(dac, channel, percent)` — convenient percent (0.0–100.0) setter.
- `DcDac_write_and_update_channel(dac, channel, value)` — write a 12-bit value and update output.
- `DcDac_eeprom_write_channel(dac, channel, value)` — write to EEPROM (slow and limited cycles).
- `DcDac_set_command_format(dac, &fmt)` — override command format if you need exact bit patterns.

Overriding command format example

```c
DcDacCmdFormat fmt = {
    .base_fast_write = 0x00,
    .base_write_update = 0x40,
    .base_eeprom_write = 0x60,
    .read_len = 8,
};
DcDac_set_command_format(&dac, &fmt);
```
