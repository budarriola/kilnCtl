Security

Set the administrator and user web passwords, the two LCD PINs, and how long each interface waits before locking. Changing a password signs out every session that was using it, including this one.

Security is not set up yet on this board: no password or PIN has ever been configured, and authentication is currently off. Set a password below for at least the administrator account before turning authentication on.

Administrator password

10-64 characters, not all lowercase, and not "password", "kiln", the username, the Wi-Fi network name, or the Wi-Fi password.

User password

Same rules as the administrator password above, checked against the fixed word list and the Wi-Fi credentials (the user account has no separate username to check against).

LCD PINs

4-8 digits. The user and administrator PINs must be different from each other. These PINs are for the LCD panel only and are set here, not on the panel.

Authentication

Each switch needs its own credential set first: web sign-in needs both the administrator and user passwords, and the LCD PIN needs both PINs.

The Dashboard and stopping a running firing never require a password, regardless of these settings.

Clear login credentials

Resets the administrator and user web passwords and both LCD PINs to unconfigured. This is separate from a factory reset -- a factory reset does not touch login credentials at all. Use this only when every password/PIN is lost.
