Safety timings

How long each thermal guard waits before it acts, and how far out of band counts as a problem. Leave a box at 0 to use the firmware's own default — the default is printed next to every field, and 0 never turns a guard off.

The limits that decide whether a guard fires at all — maximum temperature, runaway rate, cross-zone difference — are on Thermocouples & zones with the rest of the zone setup.

Whole board

Default 30000 (30 s). How long the USB link to a controlling PC may go quiet before a running firing is stopped. One setting for the whole board — it is one cable, not something a single zone experiences.
