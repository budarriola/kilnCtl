Safety relay (K4) type

Sets K4's rated contact-life budget for the dashboard/LCD relay-life indication (contactor: 100,000 cycles; mercury: 1,000,000 cycles) -- indication only, never enforced and never blocks firing. This is an ESP-only setting: the safety processor is never told and does not enforce it. The safety relay does not offer "ssr" -- only the zones/heater relays do.
