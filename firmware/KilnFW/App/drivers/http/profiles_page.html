Create and edit named firing profiles here. Run them from the Dashboard. A profile can target more than one zone; when it does, every selected zone shares one ramp/dwell schedule and the schedule waits for the slowest zone to catch up before advancing (ramp-lock) -- each zone still runs its own PID/bang-bang loop and thermal guards independently.
