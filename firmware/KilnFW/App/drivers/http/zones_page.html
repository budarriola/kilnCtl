Calibration offset is stored here but not yet applied to live readings anywhere -- that's a separate, not-yet-built change to the readout path.

A running firing profile drives this zone's relay(s) toward its target using whichever control mode is selected below -- PID mode uses these Kp/Ki/Kd values, rendered onto the relay as a slow (1-minute) on/off duty cycle, not smooth proportional output: Kp sets how hard it reacts to the current temperature error, Ki corrects slow long-term drift (e.g. never quite reaching setpoint), Kd damps overshoot from reacting too fast. The max ramp rate below is what the Fire Profiles page checks a segment's ramp rate against before letting it save. Don't know good Kp/Ki/Kd numbers for this kiln? Tuning quality

One row per zone: how well the currently-active gains were fitted. Unknown means never autotuned or hand-edited since.

What do the columns mean?

Settled/Converged/Tau ok are fit-confidence flags; a fit can be accepted with one or more false via an explicit override, so "no" doesn't mean the active gains are wrong, only lower-confidence. Extrap. correction is how much of the fitted gain was extrapolated past the trace's own data -- a large correction means a weaker fit even when every flag reads yes. This is separate from Firing quality below: a clean fit here can still fire badly (cold load, draft, bad element), or the reverse.

Firing quality

How well the kiln tracked target during past firings. Live while a firing runs, frozen once it ends.

What do the columns mean?

Mean err is signed: positive means the zone ran hot, negative cold. Max over/under are separate since overshoot and undershoot are different failure modes. IAE(norm) is normalized so different profile lengths/peaks are comparable. Ramp/dwell split the same error by segment type.

Do the zones interfere? (Relative Gain Array)

Computed from the matrix above. The bold diagonal answers "can this zone be controlled on its own?" -- 1.00 means yes.

What do other values mean?

Numbers above 1 mean the zones prop each other up and each loop works harder than it thinks; negative means the neighbours' loops reverse this zone's response. Refused outright, never estimated, when the matrix has a hole or is degenerate.
