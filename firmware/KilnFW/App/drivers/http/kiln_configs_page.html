Kiln Configs

A kiln config is a named saved snapshot of the whole zones configuration -- relay wiring, thermocouple assignment, PID gains, guard thresholds, and limits (everything Thermocouples & Zones covers) -- distinct from a firing PROFILE (a temperature schedule), which is managed on the Firing profiles page instead.

A kiln package carries everything about the kiln — wiring, sensors, tuning, guards and the safety processor's limits. It does not carry firing schedules, Wi-Fi settings, or this controller's own logs and counters.

Safety configuration mismatch — heaters disabled

The controller and the safety processor are not holding the same configuration. Applying a kiln config below re-pushes both halves together, which is the normal way to clear this.
