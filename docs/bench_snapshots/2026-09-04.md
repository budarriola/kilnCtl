## 5. Surprises / unexplained values

- **`capability_preflight_check` reports the board's firmware "version" string
  as `V1.0_Purchased_This_Board-1122-`**, distinct from the `fw_build`/commit
  fields reported elsewhere (`get_fw_version` says commit `2bcdc2d`,
  built `2026-09-04 21:53:53Z`). This looks like an ESP-IDF `PROJECT_VER`
  / version-string field that nothing else in this snapshot cross-checks —
  flagging it rather than assuming it's benign, since it doesn't match the
  commit-hash-based identity scheme used everywhere else in this repo.
- `frames_routed_nowhere: 1` on the safety link — a single stray frame with
  nowhere to route. Not zero, not explained by anything else read here.
- Adaptive tune (`adaptive_tune_get_status`): all three zones
  `enabled=False`, `observations=0` this boot and lifetime — consistent
  with an idle, freshly-booted-ish bench, not a surprise, but recorded
  since it bears on "was a campaign running in an unverified mode" concerns.
